# Harness Use · общее ядро браузера

Открытый плагин для **официального DeepSeek Harness Desktop 0.2.2-rc.3, macOS 14+**. Агент работает в собственном обычном окне Google Chrome через DevTools — без расширения и без управления личными вкладками. В комплекте остаётся отдельный помощник Computer Use.

Установщик не создаёт копию Harness, не меняет app.asar, подпись, bundle ID или штатный обновлятор. **OpenCode не устанавливается, не настраивается и не перезапускается.**

## Установка и обновление

1. Установите [официальный Harness](https://harness.deepseek.com/) и Google Chrome в «Программы». Запустите Harness один раз для создания его обычного desktop-профиля, затем завершите через Command-Q.
2. Скачайте `Harness-Use-0.4.0-macOS.zip` и `SHA256SUMS` из [Releases](https://github.com/zakras030997-byte/harness-browser-workspace/releases). Распакуйте ZIP и запустите `Install.command`.
3. Установщик добавит плагин в существующий профиль. Для зависимостей нужен Интернет; Node берётся из официального Harness, отдельная установка Node и загрузка Chromium не нужны.
4. Откройте тот же Harness и попросите открыть example.com инструментом `harness_browser_open`, затем прочитать `harness_browser_snapshot`.
5. Для добавления вкладок в отдельное окно агента один раз попросите выполнить `harness_browser_setup` и разрешите системный доступ Automation к Chrome. Настройка не создаёт вкладку и не выдаёт доступ другим приложениям. Обычные действия не вызывают этот системный запрос повторно. Вызовы инструментов по-прежнему подчиняются выбранной политике Harness.

Если приложение установлено в другом месте:

```sh
ANODHAS_HARNESS_APP="/path/to/DeepSeek Harness.app" ./Install.command
```

`./Install.command --dry-run` проверяет подпись, версию приложения и план без установки. Это не полноценная проверка установки.

Переход с пакета 0.3.x в том же каталоге выполняется без удаления. Его прежние маршруты браузера отключаются, новым становится DevTools. Для прежних отдельных ANODHAS-плагинов нужен явный `./Install.command --migrate`; см. [миграцию](docs/MIGRATION.md). Неизвестные конфликты не перезаписываются. Резервная копия профиля и предыдущий пакет сохраняются. Чаты, модели, ключи и несвязанные плагины не удаляются.

Если общий браузер используется другим клиентом или осталось неразрешённое состояние сокета, установщик остановится без замены работающего пакета. Он не завершает браузер, не перезапускает OpenCode и не изменяет его настройки. Незавершённую установку нельзя повторять вслепую.

## Что изменилось

- Один локальный процесс владеет выделенным агентским Chrome. Harness и опциональный адаптер OpenCode могут использовать общий каталог и входы, сохраняя разные окна и вкладки каждого чата. OpenCode подключается отдельно вручную, не этим установщиком.
- Для новой установки создаётся выделенный профиль Chrome агента, отдельно от личного. Личные cookies не импортируются: войдите в нужные аккаунты в окне агента. Общее агентское хранилище означает, что вход/выход влияет на оба подключённых клиента.
- Смена адреса при SSO не теряет владение вкладкой. После перехода используйте актуальный URL из `open`/`tabs`; устаревший адрес возвращает `TAB_NAVIGATED` без действия. Закрытие своей вкладки не зависит от старого адреса.
- Поля и кнопки выбираются по роли и точному имени из свежего снимка. Поддержан уникальный CSS. Отсутствующий, неоднозначный и неверный селектор различаются; произвольное первое совпадение не выбирается.
- Ошибка одной вкладки не должна блокировать закрытие или соседнюю вкладку. Неизвестный исход и тайм-аут действия не повторяются автоматически.
- Консоль JavaScript работает через DevTools только в собственной вкладке, не как системный терминал. Cookies остаются в Chrome; HttpOnly недоступны через `document.cookie`, отдельного инструмента выгрузки cookies нет. Консоль может изменять сайт и используется только в пределах поручения.

## Обучение и память

`harness_browser_read` выбирает проверенный публичный запрос; если подходящего нет — возвращается к собственной странице для обучения. Для сохранения нужны две наблюдаемые операции чтения с разным вводом и независимая проверка ответов. Поддержаны HTTPS GET JSON, один изменяемый параметр и небольшие верхнеуровневые поля, включая поле, повторяющее ввод.

После обучения знакомая операция повторяется свежим запросом без открытой страницы. Проверяются схема и смысл результата; изменившийся контракт отправляется на повторную проверку. Новый подтверждённый вариант заменяет старый без клонирования маршрутов по чатам.

Это **не автоматическое освоение любого сайта**. Универсальное обучение приватным API, POST, входам и действиям записи не реализовано. Старый эксперимент чтения меню аккаунта YouTube из расширения не переносится в новое ядро; прежние данные установщик не удаляет. Для авторизованного сайта доступны обычная страница и консоль с текущей сессией Chrome.

Память ограничена: маршруты 20 МиБ (936 публичных операций и резерв 256 КиБ/64 приватных ссылки), журнал 10 МиБ/7 дней. Разовые сайты забываются после 7 дней без успешного использования; знакомые после использования в три разных дня — до 180 дней. YouTube закреплён по возрасту, но его маршруты всё равно проверяются. Полное хранилище отклоняет новые записи, сохраняя полезные старые. Очистка происходит при работе, без отдельного фонового наблюдателя. Полные ответы, страницы и credentials в рецепты не сохраняются.

`harness_browser_memory_status` показывает фактические размеры. Лимиты не включают Chrome cache, историю чатов и RAM. Скриншоты отдельно ограничены 5 МиБ на файл, 10 МиБ суммарно и одним днём при следующем использовании захвата.

## Computer Use

В ZIP включён закреплённый upstream Cua helper 0.44.0 с лицензиями. Он запускается лениво, без CuaDriver.app, переподписи Harness и фонового автозапуска. `computer_permissions` читает реальные права; Accessibility и Screen Recording выдаёт владелец в настройках macOS.

Путь: `computer_apps` → `computer_windows` → `computer_bind_window` → свежий `computer_state` → действие по точному `action_elements` → новый state и проверка результата → `computer_release`. Сохраняются защита от устаревших токенов, запрет ввода в нередактируемое поле и карточка просмотра. Освобождение не закрывает целевую программу. Фоновый ввод подтверждён на контролируемой AppKit-форме, не на всех приложениях.

## Проверка и ограничения

В существующем официальном Harness на Luna Off проверены чтение, консоль, заполнение по роли, точный одиночный клик, вторая вкладка в своём окне и закрытие. Системный фокус не изменился. Реальный Chrome также прошёл контролируемый HTTPS SSO-редирект, сбой консоли/работу соседней вкладки и восстановление. См. [VALIDATION.md](VALIDATION.md).

Проверена Apple Silicon. Оба native helper содержат arm64/x86_64, но полный Intel-сценарий и физически другой Mac отдельно не приняты. Окна и права могут вести себя иначе на других версиях Chrome/macOS. CAPTCHA, вход и системные диалоги могут требовать владельца. Плагин не имеет собственной Developer ID-нотарификации; подпись официального Harness остаётся штатной. Старые браузерные мини-карточки и расширение остаются в исходниках для совместимости, но не включаются новым установщиком по умолчанию. В новом режиме используется обычное окно Chrome и снимки.

## Исходники и сборка

```sh
npm ci --ignore-scripts
npm run check
npm run test:shared
npm run test:computer
npm run test:learning
npm run build:native
node scripts/fetch-runtime.cjs runtime
npm run build:installer
```

Для старых extension/Chromium регрессионных проверок отдельно выполните `npm run install:browser && npm test`; обычной установке это не требуется. Native helper собирается на macOS с Command Line Tools; совместимый SDK можно указать через `ANODHAS_MACOS_SDK`.

[Описание общего ядра](shared-browser/README.md) содержит формат ручного подключения OpenCode и ограничения владения. В ZIP входят только плагин, исходники и помощники. Официальный Harness, Chrome, личные данные и конфигурация OpenCode не включаются. MIT; см. [NOTICE](NOTICE).
