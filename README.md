# ANODHAS Browser & Computer Workspace

Единый пакет для **DeepSeek Harness Desktop 0.2.2-rc.1 на macOS**: штатный внутренний браузер, изолированный Chromium, Chrome через расширение, подвижные живые карточки и инструменты фоновой работы с окнами Mac.

## Возможности

- **Внутренний Browser Harness:** вкладки, навигация, DOM-снимок, клики, ввод, клавиатура, движение указателя внутри страницы, прокрутка, JavaScript страницы, изображение и cookies текущего сайта. Инструменты `internal_browser_*` доступны глобально; управляемый чат должен быть открыт в Desktop. Чужой чат автоматически не выбирается.
- **Изолированный Chromium:** отдельная сессия чата через Playwright, без личного профиля Chrome. Подключается через `browser_enable` по запросу; создание и загрузка чатов не зависят от готовности браузерного MCP.
- **Chrome:** расширение создаёт фоновые вкладки в отдельных группах 🤖 разных цветов. Личные вкладки вне этих групп агенту недоступны. Раскрытие пользователем явно переключает нужную вкладку.
- **Карточки:** перетаскивание, изменение размера, инерция, притягивание к углам, раскрытие по двойному клику. Chrome показывает до четырёх карточек стопкой и список остальных вкладок.
- **Окна Mac:** `computer_*` — список приложений/окон, привязка точного окна к чату, изображение и дерево доступности, нажатия, ввод текста, клавиши, прокрутка и перетаскивание. Привязанное окно занято одним чатом. Карточка показывает его без перехода в приложение; закрытие карточки освобождает привязку, сохраняя приложение открытым.

Computer Use использует библиотеку [Cua Driver 0.44.0](https://github.com/trycua/cua/releases/tag/cua-driver-rs-v0.44.0), встроенную **внутрь нашей копии Harness**. Отдельное CuaDriver.app устанавливать не нужно. Внешние конфигурации Codex, Claude и Cursor не меняются.

## Совместимость

Поддерживается только macOS 14+ и [официальный Harness **0.2.2-rc.1**](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.1), build `c59d10aff167ad7eefead4b3a9082fb57c8fbfe8`. На владельческом Mac проверяется arm64; поддержка Windows/Linux и других сборок не заявлена. Установщик отклоняет неподходящую сборку. Исходный Harness остаётся на месте, отдельная копия получает локальную ad-hoc подпись; это не подпись и не нотарификация издателя Harness.

## Установка одним пакетом

1. Скачайте **ANODHAS-Browser-Computer-Workspace-0.2.1.zip** из [Releases](https://github.com/zakras030997-byte/harness-browser-workspace/releases). Распакуйте архив.
2. Завершите задачи Harness и закройте его через **⌘Q**. Установщик сам приложения не останавливает.
3. Запустите **Install.command** из архива. Нужны Интернет и оригинальный Harness в `/Applications/DeepSeek Harness.app`. Node.js и npm отдельно устанавливать не требуется: используется runtime Harness.
4. Запустите **DeepSeek Harness ANODHAS Browser.app** из `~/Applications`.

Установщик помещает плагин в `~/.dsh/extensions/anodhas-browser-workspace`, делает приватную резервную копию профиля Desktop и подключает компоненты глобально. Модели, почта, Диск, Календарь и другие записи профиля сохраняются. Chromium хранится в собственном каталоге плагина; общий кэш Playwright не очищается. Встроенный оконный runtime скачивается из закреплённого официального релиза с проверкой SHA-256 и подписи.

Если macOS блокирует `.command`, проверьте источник/контрольную сумму и используйте штатное «Открыть»/«Конфиденциальность и безопасность». Установщик не отключает Gatekeeper, SIP или проверку подписи.

### Если старый ANODHAS Browser уже установлен

Обычный запуск откажется создавать дубликат. После резервного копирования запустите в Terminal:

```sh
./Install.command --migrate
```

Отключаются только известные старые строки ANODHAS browser/native/Chrome. Неизвестные регистрации не заменяются. Папка уже подготовленной установки также не перезаписывается: сначала изучите её и выполните откат по [инструкции](docs/ARCHITECTURE.md).

### Подключение Chrome

В Chrome откройте `chrome://extensions` → включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите:

```text
~/.dsh/extensions/anodhas-browser-workspace/chrome/extension
```

Закрепите расширение и нажмите **Connect**. Native host регистрируется установщиком под отдельным именем `com.anodhas.browser_workspace`. Это разрешение Chrome выдаётся пользователем, установить его скрытно пакет не может.

### Разрешения для окон Mac

Разрешите **DeepSeek Harness** в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ» и «Запись экрана и системного аудио». Здесь нужен только видеозахват; микрофон пакет не запрашивает. После изменения разрешений штатно перезапустите нашу сборку, когда задачи завершены.

Попросите агента: «Проверь `computer_permissions`, найди открытое тестовое приложение, привяжи его окно и покажи `computer_live_view`. Работай только в фоне и проверяй результат после каждого действия».

## Работа без переключения фокуса

Все оконные действия фиксированы в режиме **background + exact window**. У агента нет инструментов активации приложения, смены Space, управления всем рабочим столом или перехода в foreground. Разрешение работать с приложением не означает разрешение отправлять сообщения, платить или менять чужие данные.

Для AppKit Cua документирует работу с окнами на другом Space без переключения пользователя. Для SwiftUI, игр, canvas и отдельных графических программ возможности ограничены: дерево может отсутствовать, ввод может не сработать. Агент обязан остановиться и сообщить ограничение. Некоторые приложения могут сами активировать своё окно в ответ на действие; изоляция всех программ не гарантируется. Фоновая отправка события не доказывает, что приложение изменилось: нужен повторный снимок/чтение. Таймаут означает неизвестный исход — повторять действие автоматически нельзя.

Это управление существующими окнами одного Mac, а не отдельная виртуальная машина. Поставьте нужное приложение на другой рабочий стол самостоятельно; пакет не управляет Mission Control. При общих файлах/документах параллельная работа всё равно может конфликтовать.

Источник ограничений: [Cua platform support](https://cua.ai/docs/cua-driver/concepts/platform-support). Подтверждённые проверки и незавершённые части перечислены в [VALIDATION.md](VALIDATION.md).

## Для разработчиков

```sh
npm ci --ignore-scripts
npm run install:browser
npm run check
npm test
npm run test:native
npm run test:computer
npm pack --ignore-scripts
```

`.tgz` — только bundle для разработчиков: для нативного Browser и окон Mac также нужен подготовленный carrier. Обычным пользователям предназначен ZIP с Install.command. Лицензия кода ANODHAS — MIT; upstream-компоненты сохраняют свои лицензии и notices.

## Закрытие миниатюры

Крестик сразу скрывает карточку. Закрытие исходной вкладки подтверждается отдельно: при потере связи или истечении ожидания интерфейс сообщает, что закрытие источника не подтверждено, и не повторяет команду автоматически. Если окно Mac просматривается через Computer Use, отключается только просмотр — само приложение продолжает работать.
