# ANODHAS Internal Browser · native addon

Управление **настоящим браузером в правой панели DeepSeek Harness Desktop**, а не отдельным headless Chromium и не внешним Chrome.

Набор из 20 глобальных инструментов: проверка подключения; список, создание, выбор и закрытие вкладок; навигация и история; снимок страницы; DOM-текст и свежие ссылки на элементы; клики, заполнение полей, движение указателя, прокрутка, клавиатура и вставка текста; JavaScript внутри страницы; получение, установка и удаление cookies текущего сайта, включая HttpOnly.

## Два компонента

1. **Bundle-плагин**: инструменты агента, маршрутизация к текущему чату и клиентский адаптер штатной панели.
2. **Native bridge основного процесса Electron**: управление принадлежащим окну webview через lease. Обычный плагин Harness не получает доступ к main process и HttpOnly cookies. Поэтому один `.tgz` без моста не обеспечивает эту функцию.

Текущий bridge рассчитан строго на **Harness 0.2.2-rc.1, build c59d10aff167ad7eefead4b3a9082fb57c8fbfe8, macOS**. Подготовщик откажется применять его к другой сборке.

## Установка без изменения исходного приложения

В постоянной папке исходников:

```sh
npm ci --ignore-scripts
node scripts/prepare-macos-app.cjs "/Applications/DeepSeek Harness.app" "$HOME/Applications/DeepSeek Harness ANODHAS.app"
```

Команда создаёт отдельную копию с мостом, обновляет ASAR integrity и проверяет её локальную ad hoc подпись. Исходное приложение не редактируется. Копия **не имеет нотарификации DeepSeek**; механизмы защиты macOS не отключаются. Если политика Mac запрещает такую локальную сборку, это ограничение нельзя считать успешной установкой.

Завершите текущие задачи и закройте Harness через ⌘Q. Затем:

```sh
node scripts/install-profile.cjs
open "$HOME/Applications/DeepSeek Harness ANODHAS.app"
```

Регистрация добавляет только этот addon в существующий desktop-профиль и сохраняет закрытые резервные копии двух изменяемых файлов. Chrome, модели, подписки и остальные подключения сохраняются. Установщик отказывается менять профиль при работающем Harness. Подготовленная копия приложения сама по себе плагин не регистрирует.

Не запускайте обе версии одновременно на одном рабочем профиле. После обновления Harness native bridge нужно проверять и собирать заново; не переносите патч на неизвестный build автоматически.

## Использование

Откройте нужный чат в Harness Desktop и поручите агенту использовать **внутренний браузер**. Сначала `internal_browser_status`, затем `internal_browser_new_tab` и `internal_browser_snapshot`. Последующие действия используют точный `tab_id` и свежий `ref`. После перезапуска сохранённую страницу можно явно восстановить через `internal_browser_select` с `restore: true`; список вкладок сам страницы не восстанавливает. Снимок приходит изображением из того же webview, который отображается в правой панели.

Инструменты регистрируются глобально. Для управления панелью конкретного чата он должен быть открыт в Desktop: чужой чат не выбирается автоматически. При переключении чата ожидающая операция прекращается или получает ошибку, вместо действия в соседнем проекте.

## Cookies и границы

- Cookies доступны только для текущего HTTP(S)-сайта данного guest. По умолчанию значения скрыты. `include_values: true` выдаёт значения, включая HttpOnly, в этот чат только при соответствующем поручении владельца. Не сохраняйте реальные значения в общих заметках или опубликованных доказательствах.
- Хранилище штатного браузера Harness разделяется на workspace по правилам самого Harness: разные вкладки проекта могут использовать один сайт и cookies. Это не личный профиль Chrome.
- Страница остаётся sandboxed, с contextIsolation и без Node. Операции не предоставляют доступ к Electron-объектам, UI приложения, паролям macOS или личному Chrome.
- Навигационные ограничения, запрет системных разрешений и диалогов штатного guest сохранены. Загрузка файлов, нативные диалоги, междоменные iframe и CAPTCHA не заявлены как решённые этим релизом. Это расширенный комплект управления страницами, а не отмена правил разрешений.
- Неизвестный исход запроса не повторяется автоматически. Платежи, сообщения и изменение данных сайтов требуют действующего поручения владельца.

## Проверки и удаление

`npm test` проверяет границы cookies, изоляцию чатов/ответов, отсутствие повторной доставки и упаковку ASAR без изменения остальных файлов. `VALIDATION.md` отделяет тестовую проверку от установки в рабочий Harness.

Для отката закройте Harness, восстановите сохранённые `package.json` и `cordis.patch.yml` из указанного installer backup и удалите только ссылку/каталог этого addon. Запустите исходный `/Applications/DeepSeek Harness.app`; он не изменялся. Не удаляйте другие плагины и native hosts.
