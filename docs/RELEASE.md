# Релиз 0.2.1

Исправлено закрытие миниатюры при Failed to fetch и зависших запросах. Крестик сразу убирает карточку, а состояние источника сообщается отдельно. Повторов команды закрытия нет.

Основной файл — ANODHAS-Browser-Computer-Workspace-0.2.1.zip с Install.command, Chrome-расширением, исходниками и инструкцией. npm tgz предназначен разработчикам. Контрольные суммы опубликованы рядом.

Версия экспериментальная: macOS14+, Harness0.2.2-rc.1 точной поддерживаемой сборки. Установка требует Интернета и обычного закрытия Harness. Обновление установленного пакета требует предварительного штатного удаления регистрации старого bundle; настройки моделей и исходное приложение сохраняются. Чистый другой Mac отдельно не проверялся.
