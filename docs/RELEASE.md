# Релиз 0.2.0

Основной файл — ANODHAS-Browser-Computer-Workspace-0.2.0.zip с Install.command, Chrome-расширением, исходниками и инструкцией. npm tgz предназначен разработчикам. Контрольные суммы опубликованы рядом.

Версия экспериментальная. Требуются поддерживаемый оригинальный Harness, Интернет при установке, ручное подключение Chrome и системные разрешения для Harness. Отдельное приложение Computer Use не устанавливается.
