# Миграция с 0.2.x

0.3.0 устанавливает плагин в исходный официальный Harness Desktop0.2.2-rc.3. Больше не создаётся приложение ANODHAS Browser, не патчатся main/preload/app.asar и не меняется подпись. Прежний updater сохраняется.

Управление старым native Electron sidebar исключено, изолированный Chromium/Chrome и карточки остаются. Computer Use использует отдельный direct helper. Его фактические OS-разрешения надо прочитать через computer_permissions; молчаливого получения прав нет.

Завершите прежний клиент. Откройте официальный Harness, если его профиль ещё не создан, затем завершите и его. Распакуйте новый ZIP. Для известного старого browser bundle выполните `./Install.command --migrate`: только известные старые browser-компоненты отключаются, остальные плагины/модели/проекты сохраняются. Unknown registration/destination останавливает установку. Старую переподписанную копию и незнакомые файлы установщик не удаляет. Не запускайте два Harness с одним профилем.

Обновление уже установленного0.3.x в том же стандартном каталоге идемпотентно по регистрации. Установщик сохраняет точную резервную копию package.json/cordis.patch.yml и прежний каталог пакета. Не удаляйте их до успешной проверки. При сбое/unknown не повторяйте запуск вслепую: прочитайте сообщение и сохранённый installation receipt.

Публичная extension identity0.2.x сохранена. Перезагрузите ту же extension после обновления. Старый ошибочный native host name исправлен на com.anodhas.browser_workspace; setup регистрирует совпадающее имя. Разрешения cookies/YouTube остаются opt-in. Личная developer-extension с другим ID автоматически не заменяется.
